# Calculadora\_Python\_EBAC

Calculadora feita durante os módulos iniciais de programação em Python!



Primeiro de tudo, baixe o Ubuntu-24.04 para utilizar o terminal Linux para visualizar este projeto. Para isso, basta abrir o Windows **PowerShell** e digitar o seguinte código:



wsl --install -d Ubuntu-24.04



Depois disso, o programa será instalado automaticamente em sua máquina, basta esperar. Quando o processo terminar e seu Ubuntu estiver instalado, caso ele não inicie sozinho, basta procurar por ele na aba pesquisar e o iniciar manualmente.



Em sua primeira inicialização, ele irá requerer um usuário e uma senha, defina ambas informações a sua escolha e pronto, você estará pronto.



Após isso, utilize mais alguns comandos para preparar o terreno para nossa calculadora. Você irá executar o comando **mkdir Calculadora** no terminal, criando um Diretório para nossos arquivos. Quando feito, verifique com o comando **ls** se nosso diretório foi mesmo criado. Após isso, basta utilizar o comando **cd ./Calculadora** para mudar para o diretório que acabou de criar.



Dentro de nosso diretório, você irá executar o comando **explorer.exe .** para abrir o explorador de arquivos diretamente no diretório em que você criou. Tendo feito isso, basta baixar os arquivos disponíveis em **projeto\_calc** e mover todos diretamente para o diretório **Calculadora** que criou.



Tendo feito tudo isso, volte para nosso terminal do Ubuntu verifique os arquivos com o comando **ls** para ver se todos estão em seu devido lugar. Execute primeiro o arquivo chamado **calc\_ini.sh** para realizar a instalação do Python3 automaticamente, caso você não tenha o mesmo instalado em sua máquina. Caso contrário, apenas execute **calc\_legal.py** para utilizar sua calculadora legal!



Obs. Os arquivos **calc\_ini.sh** e **calc\_legal.py** devem ser executados com um **./**, ou seja, ao executar um deles, seu comando será assim: **./calc\_ini.sh**



Esses dois arquivos possuem permissão para serem executáveis, porém, caso não estejam funcionando, basta realizar o comando: 

**chmod -x <arquivo que deseja alterar>**
